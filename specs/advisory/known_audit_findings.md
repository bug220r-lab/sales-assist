
# Known Audit Findings — Mandatory Implementation Acceptance Criteria

These are release-blocking engineering and test requirements. They do not reopen the approved
business decisions.

## R01 findings

1. Maintain a complete blocker/finding closure matrix with implementation artifact, version,
   ADR, accepted tests, negative tests, dependency, and re-audit scope.
2. Publish one explicit per-object fixture-envelope hash-preimage table.
3. Require canonical equality between order-level and whole-order-proof source timestamps.
4. Implement one exact content-hash-bound timestamp grammar and boundary vector set.
5. Define the exact source numeric lexeme grammar used to prove integer quantity.
6. Use a bounded generated source-import-attempt ID and resolve it to its owning retained attempt.
7. Require product-only source-object namespaces and resolution; reject phone-, VIN-, name-,
   email-, address-, and free-text-like values.
8. Add otherwise-valid privacy canaries and explicit validation precedence for every prohibited
   data class.
9. Reject DEDUPE PRESENT before adapter success when its required timestamp is unnormalizable.
10. Hash-bind the Order Number raw-source preservation rule.
11. Reproduce the timestamp primitive digest
    `ba8fc05dbdbba6fec52a3ed7b0a93a0d8dbb8512e9fe95c56d6d4bd4708d2112`.
12. Add per-domain accepted/version/null/conflict/boundary/missing/extra/noncanonical coverage.
13. Remove or implement all phantom selector-qualified oracle references; every reference must
    resolve to an actual executable test.
14. Close nested finding identity, provenance, marker, equality, and replay schemas.
15. Define finding/presence/descriptor hash domains, separators, and preimages.
16. Test every legal WWC PRESENT KNOWN/UNKNOWN partition and focused illegal combinations.

## R02 findings

1. Separate all accepted work items from terminal disposition subjects. A systemic pre-read
   failure may have one work item and zero disposition counts.
2. Serialize extraction-occurrence reservation and systemic terminalization so both forbidden
   outcomes cannot commit.
3. Add a closed second legal RC-084 emission site for pre-extraction run-level rules
   unavailability while preserving the evaluation-level site and the 138-reason inventory.

## Completion rule

A finding is closed only by executable code, test evidence, and—where consequential—an ADR.
A document assertion alone is not closure.
