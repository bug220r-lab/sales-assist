# 1. Local service and origin policy

Recommended origin:

```text
http://127.0.0.1:8765/
```

Requirements:

- bind only to `127.0.0.1` by default;
- explicit loopback host allowlist:
  - `127.0.0.1`
  - `localhost`
  - `::1`
- reject `0.0.0.0`, LAN IPs, hostnames, URLs, and external interfaces;
- bounded configurable port;
- no automatic alternate-port search without reporting the selected port;
- no external requests;
- no remote assets;
- health endpoint;
- graceful shutdown endpoint protected by local process ownership or equivalent;
- single-instance runtime receipt;
- exact app/schema/build version reporting;
- database health check before accepting evaluations;
- startup failure if migrations, safety counters, schema, or integrity checks fail.

The service may expose JSON APIs and HTML pages from one process.

```text
GET  /api/v1/runs/{synthetic_run_id}
GET  /api/v1/metrics/summary
GET  /api/v1/system/status
```

Equivalent resource design is acceptable if documented.

Requirements:

- closed request/response schemas;
- exact schema/version member;
- synthetic IDs only;
- unknown/extra members rejected;
- bounded payloads;
- no unrestricted metadata;
- no raw SQL;
- no file paths from callers;
- no database row dumps;
- no debug trace leakage;
- stable JSON error envelope;
- trusted processing times and persisted IDs;
- idempotency/request-key support where evaluation requires it;
- exact replay and conflict visibility;
- correct HTTP status classes;
- all responses contain only fictional privacy-safe values.

Portal forms/actions must call these APIs or the same application service boundary, never a duplicate rule implementation.

```text

```

Use the existing Milestone 4 backup/restore CLI/scripts.

Must:

3. acquire a single-instance lock;
4. run/verify migrations;
5. run fast DB health checks;
6. bind to loopback only;
7. start the service;
8. wait for health PASS;
9. write PID/runtime receipt;
10. open `/scenarios` in the default browser;
11. print exact version, paths, PID, and port.

## stop.ps1

Must stop only the owned process and never kill unrelated Python processes.

## status.ps1

Must report running/stopped, PID, origin, version, schema, DB path/size, safety counters, and last health status.

## reset-demo.ps1

Requires explicit confirmation, creates a backup, stops the app, clears only configured synthetic runtime data, reinitializes, verifies, and never touches source/Git/specifications.

Scripts must be tested without administrator rights.
