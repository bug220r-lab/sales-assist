  Sales Credit rule pack
- Status vocabulary: `CLOSED_M1`, `CLOSED_M1_REOPEN_ON_EXTENSION`, `CLOSED_M2`,
  `CLOSED_M2_REOPEN_ON_EXTENSION`, `PARTIAL_M2_OPEN_M3`, and `DEFERRED_NOT_IN_M2`

`DEFERRED_NOT_IN_M2` is not a waiver. It records the exact future implementation dependency and
keeps the finding release-blocking for that milestone. A `REOPEN_ON_EXTENSION` status means the
implemented domain inventory is closed, but the finding must be re-audited whenever a new hash
domain, input adapter, or owning record is added.
