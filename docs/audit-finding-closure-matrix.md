- Matrix version: `milestone3/v1`

  Sales Credit rule pack, and Milestone 3 DOI rule pack
- Status vocabulary: `CLOSED_M3` and `CLOSED_M3_REOPEN_ON_EXTENSION`

Every row is release-closed for the Milestone 3 in-memory implementation. A
`CLOSED_M3_REOPEN_ON_EXTENSION` row must be re-audited when Milestone 4 adds a durable schema,
adapter, transaction boundary, hash domain, or externally supplied evidence class. Documentation
alone is not closure: each row names implementation, collected positive tests, focused negative
tests, and the consequential ADR where one is required.
