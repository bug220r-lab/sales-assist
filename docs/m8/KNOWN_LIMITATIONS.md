# Known limitations

This is a synthetic local development/demo release, with no production-readiness claim.
It cannot connect to company systems or process real customers, orders, or credentials.
The existing GUI is retained. Broad simplification and visual redesign are deferred.

These DOI GUI actions remain absent or read-only: generic human facts, compatibility
decisions, no-alternate confirmation, out-of-scope closure, attention clearing, recheck,
intervention verification, resulting-order linking, and value correction/reversal.
The supported overlap selection does not create an intervention, resulting-order link,
or realized value. Restore and reset are separate confirmed maintenance workflows.

CPython 3.12 and Windows tzdata 2026.3 are external prerequisites, not bundled.
The exact Codex fallback is DEVELOPMENT/NONPORTABLE.
No portable runtime, compiled executable, installer, updater, remote publication, or
Chrome Web Store deployment is supplied. The extension remains 0.1.1 with sidePanel and
only the two loopback host permissions. Its last-seen state is event-bound and process-local.

The app is 0.1.1, build synthetic-sales-assist-m8/v1; API, portal DOM, dashboard DOM, and
database remain their compatible v1/v1/v1/schema-4 contracts. Migrations 0001–0004 and all
138 reasons, 138 ownership rows, and 115 transitions remain unchanged.
