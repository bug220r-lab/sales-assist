# Ten-minute synthetic manager demonstration

Use a fresh isolated demo dataset and the validated package identified in FINAL_STATUS.
The default demo paths and first-run scenario routes are in the data root's demo-routes.json.

| Time | Demonstrate |
|---|---|
| 0–1 min | Start with START.cmd. Open System and Overview; show actual health and safety counters. Explain requests, evaluations, and current queues as distinct populations. |
| 1–3 min | Open the Sales Credit target-rep case, then the human-review case. Compare system classification with the separate manager decision. Choose Approved, Denied, Partial, Other rep, or Not pursued. Partial requires positive exact minor units and currency; 1250 USD means 12.50 USD. Enter a unique request key and canonical UTC decision time, inspect the confirmation, confirm, and record. |
| 3–4 min | Submit the same form again before refreshing: exact replay returns its original receipt. Change the outcome, confirm again, and reuse the key to show conflict. Refresh to show the unchanged classification and immutable outcome history. |
| 4–6 min | Open the DOI fulfillment split and unresolved overlap. Show separate 10.00 USD and 20.00 USD opportunities and exact line scopes. Confirm one offered scenario with a key and observation time. Repeat for replay, change selection for conflict, then refresh. The aggregate becomes available for the selected scenario; no intervention or realized value is created. |
| 6–7 min | Open Human review and an Audit-only view from a case. Current work and immutable history have different purposes. |
| 7–8 min | If extension validation is complete, open a supported synthetic order and the dedicated Chrome side panel. Evaluate and follow its Control Center link. Describe the actual last-seen state. If validation is pending, disclose that and omit this step. |
| 8–9 min | Open System → Telemetry. Show the 15 denominator definitions, N/A empty rates, exact currency separation, and the labeled historical performance reference. Fresh measurements are in external release evidence. |
| 9–10 min | Open System → Backups, enter a new request key, confirm and create a verified backup. Select Refresh backup receipts, inspect its receipt, then STOP.cmd. Restart to show persisted history. Explain the limits below. |

Use canonical UTC times later than the displayed case update, such as the current UTC time.
After a decision is recorded, its form disappears on refresh because the action is complete.
Use a new disposable demo installation for a fresh walkthrough; do not clear historical evidence.
